# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Instead, contact the maintainers via:

- Security advisory: `https://github.com/{{GITHUB_ORG_OR_USER}}/{{REPO_NAME}}/security/advisories/new`
- Email: `security@{{YOUR_DOMAIN}}`
