# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

- Expected behavior: be respectful, constructive, and collaborative.
- Unacceptable behavior: harassment, discrimination, or personal attacks.

Maintainers may remove comments, commits, issues, or contributors who violate
