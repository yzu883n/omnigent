# Base Repo Template Setup Checklist

Use this checklist after cloning the template.

- [ ] Replace all `{{PLACEHOLDER}}` values across files.
- [ ] Confirm `README.md` quick-start commands work.
- [ ] Update `SECURITY.md` contact channels.
- [ ] Set code owners in `.github/CODEOWNERS`.
- [ ] Customize CI workflow with project lint/test/build commands.
- [ ] Configure branch protection rules in GitHub.
- [ ] Enable Dependabot and secret scanning in GitHub settings.
- [ ] Add an initial changelog or release process document.
